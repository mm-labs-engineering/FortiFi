# FortiFi Assets

This directory contains the FortiFi logo and other brand assets.

## Logo

The FortiFi logo should be placed here as `logo.png`. The logo features:
- Green shield with keyhole design
- Represents security and access control
- Used in README, documentation, and demo pages

## Usage

The logo is referenced in:
- `README.md` - Main repository header
- `docs/README.md` - Documentation header  
- `examples/demo/src/views/index.html` - Demo page header

## File Requirements

- **Format**: PNG
- **Name**: `logo.png`
- **Recommended size**: 400x160px (2.5:1 aspect ratio)
- **Background**: Transparent or white
